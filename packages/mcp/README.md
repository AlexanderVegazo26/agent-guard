# @alexvegman/mcp

MCP server (`agentguard-mcp`) exposing [AgentGuard](https://github.com/AlexanderVegazo26/agent-guard)'s review, guard, and reporting capabilities to any MCP-compatible client.

## Install

```
npm install -g @alexvegman/mcp
```

## Depends on

[`@alexvegman/core`](https://www.npmjs.com/package/@alexvegman/core), [`@alexvegman/decision`](https://www.npmjs.com/package/@alexvegman/decision), [`@alexvegman/assertions`](https://www.npmjs.com/package/@alexvegman/assertions), [`@alexvegman/reporters`](https://www.npmjs.com/package/@alexvegman/reporters), [`@alexvegman/observe`](https://www.npmjs.com/package/@alexvegman/observe).

Full documentation: [github.com/AlexanderVegazo26/agent-guard](https://github.com/AlexanderVegazo26/agent-guard).
